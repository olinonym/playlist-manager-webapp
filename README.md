# 🎵 Music Playlist Manager (PHP)
A simple PHP-based music playlist manager for Mid-term Project in Data Structure and Algorithm Subject

## 📝 Features
- Create a new playlist
- Insert a song at the end
- Insert a song at a specific position
- Search for a song
- Delete a song
- Play, Next, Previous controls
- Archive old playlists
- Load and delete archived playlists
- Highlight currently playing song

## 🚀 Installation
- Download and install XAMPP from https://www.apachefriends.org
- Start Apache Server
- Open XAMPP Control Panel → Start Apache.
- Copy Project Files
- Copy the entire project folder (playlist-manager) into htdocs folder inside XAMPP directory. Example: `C:\xampp\htdocs\playlist-manager`
- Open in Browser
- Open your browser and navigate to: `http://localhost/playlist-manager/`
- Start Using the App

## 🖥 Usage
- Create Playlist: Click `+ Create new playlist`.
- Add Song: Enter song name → Click `Insert song`.
- Insert at Position: Enter song name and position → Click `Insert at Position`.
- Search Song: Enter song name → Click `Search song`.
- Delete Song: Enter song name → Click `Delete song`.
- Play Songs: Use `▶`, navigate with `⏭` (Next) or `⏮` (Previous).
- Archive Playlists: Old playlists appear in sidebar; load or delete as needed.
